Cardápio digital com QR Code e garçom IA para restaurantes.

Três áreas, cada uma na sua pasta

  • Não precisa de Node, npm ou build — é HTML/CSS/JS puro.
  • Abra qualquer index.html com a extensão Live Server do VS Code.
  • admin/ — você cadastra restaurantes e gera QR Codes.
  • restaurante/ — painel de cada restaurante (link com token, gerado pelo admin).
  • cliente/ — cardápio público, acessado pelo QR Code da mesa.
